# Lighthouse logo

Mode: built-in image_gen, reference-based generation and refinement.

Design brief (reconstructed; the exact tool prompt was not retained):
Use the supplied cellular antenna photograph as the subject and the existing
Lighthouse navy/parchment palette. Create a readable small launcher icon:
a bold cellular mast with two main antenna panels, a few lower equipment boxes
and cable loops, and a simplified building at lower right. Add modest technical
detail without clutter. No letters, no RU, no caption. Opaque full-bleed square
background without a white border or baked-in launcher frame.

Final asset: lighthouse-logo-source.png. Android uses adaptive icons; legacy and
desktop sizes are produced by tools/generate_icons.py. No application release was built.
